## Registering a new map

1. Repo name ends in `-map`; one canonical repo per map.
2. Create it under `shaun-agent` (public unless it must be restricted).
3. Add a row here — public maps get a link; restricted maps are listed by name only.
4. Follow the recipe in [mental-map-map](https://github.com/shaun-agent/mental-map-map).
